AK Smarts Books - update 2026-10-31
===================================
UPLOAD ORDER: put the new licence server worker.js online first, then this website.

New in this update
  * Sign-up page: new users see a "Start your 30-day free trial" form
    (name, email, phone, location, then business name). The details are
    sent once to the AK Smarts licence server so you are alerted (admin page
    popup, optional email to info@aksmarts.com). Books are never sent.
    If the computer is offline, it is sent when it next comes online.
    Existing users with books are not asked.
  * Support contact everywhere: info@aksmarts.com, WhatsApp / call
    +91 63639 44409. Setup, Licence has "Send ID on WhatsApp" and
    "Send ID by email" buttons that fill in the installation ID for you.
  * Dashboard redesigned. Bigger, easier-to-read text everywhere, plus an
    "Aa" button in the top bar for Large / Extra large text.
  * Chart of accounts: built-in ledgers start unticked (hidden); tick the
    ones you use. Main group names cannot be edited.
  * Statutory compliance is now a drop-down menu: GST, GST refund, TDS and
    TCS, EPF/ESI/PT, Payroll dues, Compliance calendar.
  * Move up / move down buttons on journal lines and invoice item lines.
  * Backup and restore: back up to this computer/USB, Google Drive or
    OneDrive, and restore from any of them. Admin AND staff can restore.
  * The "Google Drive is not set up" panel is removed. Data menu now has
    "Backup and restore" and "Auto-save to a file".
  * Companies limit: the app reports how many companies are in use to the
    licence server, so you see it in the admin page. Creating more than the
    licence allows is blocked.

  * Shared books for a team (Data -> Auto-save to a file -> "Shared with your team"):
    keep one file in a shared Google Drive / OneDrive folder. First person:
    "Choose where to save" there. Others: "Open books from a file", same file.
    Only one person edits at a time. Everyone else sees "View only: <name> is
    editing" and the latest saved copy, refreshed about every minute. Buttons:
    "Let others edit", "Start editing", "Edit now (take over)". An editor who is
    away for 20 minutes is released automatically.

  * Chart of accounts: built-in ledgers now start unticked (hidden); tick the
    ones you need. Ledgers with entries are always in use. Groups open on click.
    Main (built-in) groups can no longer be renamed.
  * Repeating entries now have a Type: expense, income (e.g. rent received)
    or journal.
  * Data -> Move to other software: Tally-style XML, journal CSV/Excel, chart
    of accounts, contacts and trial balance, or everything in one zip.

Upload order: licence server update first (aksmarts-licence-server.zip,
paste the new worker.js), then this website.

AK Smarts Books - update for books.aksmarts.com
================================================
What changed
  * Web addresses no longer show ".html":
        https://books.aksmarts.com/          landing page
        https://books.aksmarts.com/app       the app
        https://books.aksmarts.com/terms     Terms
        https://books.aksmarts.com/privacy   Privacy
  * The app file is now app.html (GitHub Pages serves it as /app).
  * Offline support (sw.js) now loads pages from the internet first, so
    updates always appear, and only uses the saved copy when offline.
    This fixes the "Open does nothing after installing" problem caused
    by an old saved copy.
  * Installed app now starts at /app.

How to upload (GitHub repo -> Add file -> Upload files)
  1. Delete the old app file first if it is still there:
     AK-Smarts-FinDesk.html (and any old AK-Smarts-Books.html is fine,
     the new one is only a small redirect to /app).
  2. Drag in ALL files from this zip (including CNAME and .nojekyll),
     commit.
  3. Wait 1-2 minutes, then open https://books.aksmarts.com

If you already installed the old version
  Open the installed app once while online and close it. The new offline
  file replaces the old one automatically. If it still looks old:
  Chrome -> address bar -> padlock -> Site settings -> Clear data, then
  open https://books.aksmarts.com again. (Your books are stored in the
  browser: first use Back up in the app, then clear.)

Note: oauth.html is only the small pop-up page Google Drive sign-in
returns to. It keeps its name because Google is set to that address.

LICENCE CHECK (new)
  app.html now asks https://licence.aksmarts.com once a day whether the computer is the licensed one.
  Set up the licence server first (see SETUP-licence-server.txt in aksmarts-licence-server.zip),
  then upload this site. Without the server the app still works (7-day offline grace).
  The privacy page, terms and landing page were updated to describe this.
