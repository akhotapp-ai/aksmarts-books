STEP 1 — Upload to GitHub (replace the old files)
-----------------------------------------------------
1. Unzip aksmarts-books-site.zip on your computer.
2. Go to your repo:  github.com/akhotapp-ai/Smarts-FinDesk-AK-
   (the repo name doesn't matter — you can keep it or rename it)
3. IMPORTANT — remove the old app file first so it doesn't linger:
   - Open  AK-Smarts-FinDesk.html  in the repo, click the trash/Delete
     icon, Commit. (Leave the rest; the upload below overwrites them.)
4. Click  "Add file"  ->  "Upload files".
5. Drag in ALL the unzipped files (including CNAME and .nojekyll).
6. Click  "Commit changes".

NOTE: The CNAME file in the zip already contains books.aksmarts.com,
so once it's uploaded, GitHub Pages picks up the domain automatically.
If you created an old CNAME earlier with "findesk.aksmarts.com",
this upload replaces it.

-----------------------------------------------------
STEP 2 — GoDaddy DNS  (change the subdomain to "books")
-----------------------------------------------------
1. godaddy.com -> My Products -> aksmarts.com -> DNS (Manage DNS).
2. If you already added a "findesk" CNAME earlier, EDIT it (or delete
   it and Add New Record). Set it to EXACTLY:

      Type:   CNAME
      Name:   books
      Value:  akhotapp-ai.github.io
      TTL:    1 Hour  (or default)

3. Save.  (Value has NO https:// and NO slash at the end.)

-----------------------------------------------------
STEP 3 — GitHub Pages setting
-----------------------------------------------------
Repo -> Settings -> Pages -> Custom domain -> type:
      books.aksmarts.com
Save. Tick "Enforce HTTPS" once it becomes available.

-----------------------------------------------------
STEP 4 — Wait, then open
-----------------------------------------------------
After 10-30 minutes:
      https://books.aksmarts.com
You should see the AK Smarts Books landing page. Done!
